# FastWY

Консольный прототип поиска статистически значимых подгрупп. Использует правосторонний точный тест Фишера и одношаговую перестановочную поправку Westfall–Young minP при α = 0,05.

## Сборка и запуск

Нужен компилятор C++14. Для сборки через CMake нужна версия 3.12 или новее. Из каталога проекта:

```powershell
cmake -S . -B build
cmake --build build --config Release
Push-Location build
ctest -C Release --output-on-failure
Pop-Location
```

Прямая сборка с GCC и проверка на небольшом примере:

```powershell
g++ -std=c++14 -O2 src/main.cpp src/fastwy.cpp -o fastwy.exe
.\fastwy.exe data/sample_item.csv data/sample_expression_over1.csv --exact
.\fastwy.exe data/sample_item.csv data/sample_expression_over1.csv 1000 42
```

Вторая команда перебирает все размещения меток при фиксированном числе положительных объектов. Режим ограничен 20 объектами и предназначен для проверки. Третья команда использует 1 000 случайных перестановок и seed 42. В случайном режиме допускается от 1 до 10 000 перестановок. Для сравнения между реализациями передайте те же метки:

```powershell
.\fastwy.exe items.csv labels.csv --permutation-file permutations.csv
```

## Форматы

Первый CSV содержит заголовок, идентификатор объекта и столбцы бинарных признаков. Второй CSV содержит заголовок и два столбца: идентификатор и бинарная метка. Идентификаторы уникальны и идут в одном порядке в обоих файлах. В выборке присутствуют оба класса. Поддерживается CSV с запятыми, без кавычек, пропусков и пустых строк. Файл перестановок без заголовка. Каждая строка содержит N бинарных меток в порядке объектов и сохраняет исходное число единиц.

Вывод — TSV. Строки метаданных содержат α, число перестановок, скорректированный порог для исходных p-значений и количество найденных наборов. Для каждого набора программа выводит поддержку, число положительных объектов, исходное p и перестановочную долю minP ≤ p. Порог 0 означает отсутствие допустимого положительного порога.

## Как работает прототип

Майнер перечисляет замкнутые наборы с заданным диапазоном поддержек. У наборов с одинаковым покрытием совпадает статистика при любой перестановке меток. Их представляет один замкнутый набор. Интерфейс Miner отделяет перечисление от статистического ядра.

Ядро просматривает наборы по убывающим диапазонам поддержки. Для каждой перестановки хранится свой минимум. Ниже числа положительных объектов граница минимального достижимого p монотонна по поддержке. Перестановка выходит из дальнейшего поиска, когда текущий минимум уже нельзя улучшить. Гипергеометрические хвосты вычисляются в логарифмической шкале и кэшируются по поддержке.

Из отсортированных минимумов берётся наибольшее наблюдавшееся значение, для которого не более floor(B/20) минимумов лежат на пороге или ниже. Если совпадающие минимумы пересекают эту границу, порог отступает перед всей группой. Поэтому на пограничных примерах правило может отличаться от авторского кода. Программа применяет порог к исходным p-значениям.

## Эталон

Файлы в data взяты из [авторского репозитория LAMP](https://github.com/a-terada/lamp/tree/master/sample). На примере 15 × 4 полный перебор 6 435 размещений даёт порог 57/6435 и набор TF1,TF2,TF3. Поддержка 5, все пять объектов положительные. Исходное p равно 45/6435, скорректированная доля равна 54/6435. Ожидаемый результат сохранён в tests/toy_expected.tsv.

## Эксперименты

[Протокол, результаты и воспроизведение](experiments/README.md).

Сырые наборы для подготовки UCI можно получить из первичных источников:

- [Mushroom](https://archive.ics.uci.edu/dataset/73/mushroom), файл agaricus-lepiota.data.
- [Tic-Tac-Toe Endgame](https://archive.ics.uci.edu/dataset/101/tic+tac+toe+endgame), файл tic-tac-toe.data.

Поместите оба файла в data/uci/raw и выполните python scripts/prepare_uci.py.
Для сверки с авторским кодом используются Python 3.12 и GCC. Исходный эталон — [LAMP, коммит 4bda274](https://github.com/a-terada/lamp/tree/4bda274138d12c7ea39b2a848672a10247f32f0a). Для проверок Windows предусмотрены scripts/prepare_reference.py, scripts/run_reference.py и scripts/measure_windows.py.
